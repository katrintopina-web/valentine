# Валентинка мужу 💌 (зашифрованная)

Личный проект. К рабочему вайлу JobBrain отношения не имеет.

Открытка с конвертом и переворотом. Фото и тексты **зашифрованы паролем** — публично лежит
только `vault.enc`, без пароля его не открыть. Ссылка одна и та же каждый день, содержимое
меняется по дате.

---

## Файлы

| Файл | Где живёт | Что это |
|------|-----------|---------|
| `messages.js` | **только у тебя** (в git не идёт) | твои тексты и какие фото к каким дням |
| `photos/` | **только у тебя** (в git не идёт) | исходные фото: `1.jpg`, `2.jpg` … |
| `encrypt.html` | **только у тебя** | локальный шифровальщик → делает `vault.enc` |
| `index.html` | в репозитории | сама страница с паролем и конвертом |
| `vault.enc` | в репозитории | зашифрованные фото+тексты |
| `.github/workflows/valentine.yml` | в репозитории | утренний бот со ссылкой |

`messages.js`, `photos/`, `encrypt.html` перечислены в `.gitignore` — они остаются только на твоём
компьютере. В интернет уходят лишь `index.html` и `vault.enc`.

---

## Как поменять открытки на неделю

1. Открой `messages.js` (Блокнот), поправь `title` / `text` по дням, при необходимости
   поменяй фото в папке `photos/` (имена — по номеру дня).
2. Открой `encrypt.html` двойным кликом.
3. Введи **пароль** (тот же, что дала мужу), выбери все фото недели, нажми **«Собрать vault.enc»**.
4. Скачается `vault.enc` — положи его в эту папку (замени старый).
5. Залей:
   ```bash
   git add vault.enc
   git commit -m "Открытки на неделю"
   git push
   ```
6. Через ~1 минуту страница по ссылке обновится.

Проверить локально до заливки: двойной клик по `index.html` — пока `messages.js` лежит рядом,
страница откроется **без пароля** и покажет реальный вид с фото.

## Разовая настройка

### 1. Репозиторий на GitHub
Создай **новый репозиторий** `valentine` (можно публичный — внутри только шифр).
Потом в этой папке:
```bash
git init
git add .
git commit -m "Валентинка"
git remote add origin https://github.com/katrintopina-web/valentine.git
git branch -M main
git push -u origin main
```

### 2. GitHub Pages
Репозиторий → **Settings → Pages** → Source: **Deploy from a branch** → **main / (root)** → Save.
Через минуту появится адрес:
```
https://katrintopina-web.github.io/valentine/
```
Впиши его в `.github/workflows/valentine.yml` (строка `SITE_URL`), затем `git add`, `commit`, `push`.

### 3. Пароль
Придумай пароль-фразу (3–4 слова). Прогонишь через `encrypt.html` (шаги выше) → получишь `vault.enc` →
`git add vault.enc && git commit -m "vault" && git push`.
Пароль **один раз** отправь мужу в Телеграм. Его телефон запомнит — дальше просто открывает ссылку.

### 4. Телеграм-бот
1. В Телеграме напиши **@BotFather** → `/newbot` → имя и username → сохрани **токен**.
2. Дай мужу ссылку на бота, пусть нажмёт **Start** (бот не может написать первым).
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → найди `"chat":{"id":...}` —
   это **chat_id мужа**.

### 5. Секреты репозитория
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Name | Value |
|------|-------|
| `TELEGRAM_BOT_TOKEN` | токен из шага 4 |
| `TELEGRAM_CHAT_ID` | число из шага 4 |

### 6. Проверка
Репозиторий → **Actions** → **Morning valentine** → **Run workflow**. Мужу должна прийти ссылка.
Дальше — каждое утро автоматически.

---

## Если что-то не так

- Ссылка не пришла → **Actions** → последний запуск → смотри красный шаг. Частые причины:
  не тот `TELEGRAM_CHAT_ID`, муж не нажал Start, опечатка в токене.
- «Неверный пароль» у мужа → проверь, что прогоняла `encrypt.html` с тем же паролем, что дала ему.
- Страница пустая → не залит `vault.enc`, либо Pages ещё не собрался (подожди минуту).
- Расписание отключилось → GitHub гасит его после 60 дней без коммитов. Делай `git push` хотя бы раз в неделю (ты и так будешь).
